# 🎨 STRIPE Branding Guidelines

## Logo & Identity

### Primary Logo
- **File**: `frontend/web/public/logo.svg`
- **Colors**: Blurple #635BFF
- **Usage**: Homepage, brand materials
- **Variations**: Square, horizontal, icon

### Logo Variants
1. **Full Logo** (`logo.svg`) - Standalone with accent elements
2. **Horizontal Logo** (`logo-horizontal.svg`) - For navbar
3. **Favicon** (`favicon.svg`) - Browser tab icon

### Logo Design Principles
✅ **Minimalist** - Clean, modern aesthetic  
✅ **Versatile** - Works at any size  
✅ **Stripe-inspired** - Curved, elegant S shape  
✅ **Video-focused** - Subtle play icon integration  
✅ **Professional** - Premium finishes

## Typography

- **Font**: Inter (Google Fonts)
- **Headings**: Inter Bold (700, 800)
- **Body**: Inter Regular (400)
- **Captions**: Inter Medium (500)
- **Mono**: IBM Plex Mono

---

## Logo Usage Examples

### ✅ Correct Usage
- Logo on solid backgrounds
- Clear space around logo
- Minimum size: 32px
- Proper contrast ratios

### ❌ Incorrect Usage
- Rotating or skewing
- Changing colors without permission
- Placing on conflicting backgrounds
- Resizing disproportionately
